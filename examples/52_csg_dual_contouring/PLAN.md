# Example 52: Neurosymbolic CSG & GPU Dual Contouring (ID-Aware)

This example adapts the neurosymbolic character generation from Example 51, shifting from pure SDF sphere-tracing to GPU-accelerated mesh baking via Dual Contouring (DC). It retains the anthropometric "muscle" shapes but compiles them into a skinned mesh with automatic bone weights and sharp ID-based material boundaries.

## 📋 Core Components

### 1. CSG Primitive Library
The mathematical functions from 51 are reused to define Constructive Solid Geometry (CSG) primitives. The shapes (spheres, capsules, ellipsoids, boxes) remain identical to preserve the polished anatomical look.

### 2. Hierarchical TF Skeleton
Maintains the Lua-side transformation tree. Instead of evaluating the SDF globally per pixel in a raymarcher, the skeleton is used to evaluate the CSG field within a 3D grid during the baking phase.

### 3. GPU Dual Contouring Pipeline
The mesh generation runs entirely on the GPU via compute shaders:
- **Phase 1: Field Evaluation (`field.comp`)**
  Evaluates the CSG field into a dense (or sparse) 3D grid of voxels. For each voxel corner, we compute the distance, the material ID, and automatic bone weights (based on the nearest primitives' bones).
- **Phase 2: Vertex Generation (`vertex.comp`)**
  For each voxel containing a surface (a sign change), a vertex is placed. To ensure sharp material boundaries, we prevent blending across different IDs. If an edge crosses an ID boundary, the generated vertex accounts for this to create a crisp seam.
- **Phase 3: Index Generation (`index.comp`)**
  Generates triangles (indices) connecting the vertices for each active edge.

### 4. Automatic Skinning & Rendering
- **Bone Weights:** During field evaluation, skinning weights are automatically generated by blending the influence of the closest bone shapes.
- **Rasterization:** The final mesh is drawn using a standard Vulkan graphics pipeline with a vertex shader (`skinning.vert`) that applies skeletal animation, replacing the raymarching compute shader.
